GCEstimjmv 1.1.1 — LOW audit corrections
Validation date: 28 October 2026; local jamovi 2.7.41 on Windows.

1. Plot invalidation
Replaced the seven broad presentation dependency lists with dependencies used
by each renderer. All existing estimation dependencies remain intact.
Additional presentation dependencies (besides each plot's own visibility option):
  Paths: selection, manualIndex, axisScale, showIntercept, extrema, facet,
         displayTerms.
  Ranges: selection, manualIndex, showIntercept, displayTerms.
  Sensitivity/Stability: selection, manualIndex, axisScale, showIntercept,
                         displayTerms; CV remains an estimation dependency.
  CV: axisScale, seBars. Its simultaneous minimum/1-SE markers do not depend
      on the selected rule or manual grid position.
  Sample: selection, manualIndex, axisScale.
  Folds: selection, manualIndex, axisScale, foldMean.
Per-plot saved presentation state contains only relevant options. When the
numerical cache is reused, unchanged image states are not rebuilt or reset.
Automated tests exercise actual jmvcore invalidation and backend build counts.
Actual GUI evidence: changing only CV mean ± 1 SE changed the CV image;
all six other image paths and bytes remained identical in saved OMV files.
The complete numerical cache remained identical across that change.

2. Incompatible options
Standardization uses enable: (intercept). Its stored preference is preserved;
the effective value passed to GCEstim is FALSE without an intercept. The
summary says Not applicable. Effective estimation settings are recorded in new
caches and checked by the backend; released caches remain reusable. Existing
conservative estimation clearWith declarations are retained.
Stored 1-SE with CV disabled uses minimum returned in-sample error, without
rejecting the analysis or attempting 1-SE. An INFO notice explains the
descriptive fallback and retained preference. Tables, markers and plot state
use the effective selection. Re-enabling CV restores the stored preference.
Automated repeated transitions and actual GUI off/on transitions passed.
CV-enabled mathematical selection rules are unchanged.

3. Numerical lambda presentation
Model Summary now contains settings and metadata. A compact Selected Lambda
table uses type: number for minimum evaluated, maximum evaluated and selected
lambda; the rule is text. Values retain full floating-point precision and use
jamovi number formatting. The coefficient table title uses approximately three
significant digits. Lambda Results and selection indicators remain available.
GUI example: numeric selected value 26.560877829466854 displayed as 26.6,
matching the concise coefficient-table title, without reducing stored precision.

4. Notices, captions and caveats
Removed general explanatory captions from all seven Ridge Trace images.
Retained statistical caveats in table footnotes and full-data preprocessing
INFO when CV and effective standardization are enabled. Removed repeated
general not-confidence-interval explanations from INFO. Invalid/unavailable
numerical result warnings remain. Fold/full-data trajectory identification
and fold-error/mean-overlay legends remain meaningful.
Shared entropy presentation no longer places recovery warnings in exported
plots. TARWGCE and TASWGCE issue a WARNING Notice for genuine recovery
failures while preserving valid graphics. Recovery calculations are unchanged.

5. Development-only migrations
Removed Ridge Trace option/image cleanup helpers and their calls, including
the undocumented options$.removeOption() dependency. No replacement migration
was necessary. Unknown obsolete options are ignored; unrelated analyses do not
depend on the removed helpers. Tests restore genuine v1.1.0 numerical and image
states, prohibit estimator calls and verify reuse, filtering and selection.
Current saved OMV files were actually saved, closed and reopened in jamovi;
the reopened Ridge Trace analysis reported reuse of the previous fit.

6. Labels
All seven plot titles use title case:
Ridge Coefficient Paths; Cross-Validation Error; In-Sample Error;
Coefficient Ranges; Local Coefficient Sensitivity; Fold-Specific CV Errors;
Coefficient Stability Across CV Folds.
Options now read CV mean ± 1 SE and Manual (grid position).
YAML contains the literal Unicode ±; R text uses \u00B1 where appropriate.
NEWS and Ridge Trace documentation describe audit fixes, not new statistics.
Historical v1.1.0 NEWS is unchanged. Version remains 1.1.1 throughout.
